## Расчётный темп развития

Сценарий использует два ручных удара в секунду без пауз. На каждом шаге игрок копит на улучшение с минимальным отношением цены к приросту дохода при этом темпе; при равенстве выбирается более дешёвое. Покупка происходит сразу после накопления нужной суммы. Это моделирование, а не замер времени реального игрока.

| Событие | Время от начала |
| --- | --- |
| Первая покупка | 15 с |
| Первая смена внешнего вида инструмента | 42,5 с |
| Сталь | 1 мин 11 с |
| Узорчатая сталь и все достижения | 3 мин 23 с |
| Все двадцать улучшений | 5 мин 21,5 с |

Первая покупка укладывается в ориентир 15–20 секунд из игровых правил. Цены и формулы сохранены.
