## Расчётный темп развития

Сценарий использует два ручных удара в секунду без пауз. На каждом шаге игрок копит на улучшение с минимальным отношением цены к приросту дохода при этом темпе; при равенстве выбирается более дешёвое. Покупка происходит сразу после накопления нужной суммы. Это моделирование, а не замер времени реального игрока.

| Событие | Время от начала |
| --- | --- |
| Первая покупка | 15 с |
| Первая смена внешнего вида инструмента | 42,5 с |
| Сталь | 1 мин 11 с |
| Узорчатая сталь и все достижения | 3 мин 23 с |
| Все двадцать улучшений | 5 мин 21,5 с |

Первая покупка укладывается в ориентир 15–20 секунд из игровых правил. Цены и формулы сохранены.

## Границы проверки

- Размеры экрана проверены во встроенном браузере; отдельные Chrome, Firefox, Safari и реальные телефоны в этом прогоне не использовались.
- Ошибки хранилища проверены автоматическими тестами с имитацией доступа. Поведение конкретных приватных режимов браузеров не подтверждено.
- Начисление за длительный промежуток без обновлений проверено управляемыми часами. Фоновые ограничения мобильных браузеров требуют проверки на устройствах.
- На пятом этапе проверены ограничение числа эффектов при 2 000 вызовах, их очистка, обработка уменьшения движения и соответствующее CSS-правило. Системное переключение уменьшения движения во встроенном браузере недоступно.
